# CLAUDE.md: UPlayer

## Порядок работы с файлами (экономия токенов)

1. Единственный файл, который читается целиком: `README.md`. Там решения пользователя и то, как сайт отдаёт видео. Читай его один раз за чат.
2. Карта файлов: `docs/MAP.md`, одна строка на файл: путь и за что он отвечает. Сначала смотри карту, потом открывай нужный файл. Если карты нет, создай её в первой задаче.
3. Остальные файлы не читай целиком. Ищи через Grep, открывай нужные строки через offset и limit.
4. Не перечитывай файл, который уже читал в этом чате, если его не меняли.
5. В ответах не пересказывай код. Ссылайся на путь и номер строки.
6. Вывод adb, сборок и логов фильтруй (grep, tail, head), не выводи целиком.
7. Создал новый файл или поменял его назначение: обнови строку в `docs/MAP.md`. Устаревшую строку удаляй.

## Выбор модели

Переключай вручную командой `/model`. Модель сама не меняется.

- **Haiku** (`/model haiku`): ЛЁГКИЕ задачи. Переименования, правки строк и текстов, форматирование, отметки в `TASKS.md`, правки `docs/MAP.md`, коммиты, механический перенос по готовому плану.
- **Sonnet** (`/model sonnet`, по умолчанию): реализация экранов и фокуса, интеграция ExoPlayer, обычные баги, тесты.
- **Opus** (`/model opus`): планирование задачи, сложная отладка HLS-воспроизведения на приставке, любые решения, которые меняют `README.md`.

Если в задаче есть и сложная, и лёгкая часть: сначала сделай сложную на Sonnet или Opus, потом переключись на Haiku.

## Задачи

- Задачи лежат в `TASKS.md`. Одна задача за чат.
- Перед задачей прочитай её описание в `TASKS.md` и только нужные строки кода.
- После задачи: отметь её в `TASKS.md`, закоммить, запушь и остановись. Следующую задачу начинай в новом чате.

## Стек (утверждён в README, без вопроса не менять)

- Kotlin, Leanback. Без Compose: приставка слабая.
- Media3 ExoPlayer с HLS.
- Без нативного кода и без Google Play Services.
- minSdk 23.

## Решения пользователя (без вопроса не менять)

- «Только каталог»
- «Без памяти» (кроме UUID установки, времени пинга и флага статистики, см. README)
- «Статистика устройств»: раз в сутки обезличенный пинг на irlme.online; по умолчанию включена, пользователь выключает в настройках; список полей менять только с вопросом и правкой README
- «Без рекламы»
- «Любые Android TV»

Полный список решений смотри в `README.md`.

## Управление

Только пультом. У каждого элемента интерфейса понятный фокус.

## Сборка

- JDK 17: `~/.local/opt/jdk-17.0.21+9`
- Android SDK: `~/.local/opt/android-sdk`

## Проверка на приставке

- Приставка: Rombica Go, `192.168.31.185`.
- adb напрямую из `~/.local/opt/android-sdk/platform-tools`.
- Отладку по сети пользователь включает и выключает сам. Не включай её и не предлагай как постоянную.
- Проект cleanyourtv чужой. Не открывай его, не меняй и не запускай его команды.
- Большие APK по Wi-Fi передаются плохо. Положи файл на флешку и установи:
  `cat /storage/<флешка>/<файл>.apk | pm install -S <размер>`
  Размер указывается в байтах.
