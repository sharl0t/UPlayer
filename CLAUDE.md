# CLAUDE.md: UTvPlayer

Сначала прочитай README.md: там решения пользователя и то, как сайт отдаёт видео.

- Язык общения, комментариев к коммитам и документов: русский. Без длинного тире «—».
- Стек утверждён, см. README: Kotlin, Leanback (без Compose,
  приставка слабая), Media3 ExoPlayer с HLS, без нативного кода и Google Play Services, minSdk 23.
- Управление только пультом: у каждого элемента понятный фокус.
- Сборка: JDK 17 `~/.local/opt/jdk-17.0.21+9`, Android SDK `~/.local/opt/android-sdk`.
- Проверка на приставке Rombica Go `192.168.31.185`: напрямую `adb` из `~/.local/opt/android-sdk/platform-tools`
  (проект cleanyourtv чужой, его не трогать; отладку по сети
  пользователь включает сам и выключает после). Большие APK по Wi-Fi приставки передаются плохо: класть на
  флешку и ставить `cat /storage/<флешка>/<файл>.apk | pm install -S <размер>`.
- Репозиторий GitHub `sharl0t/UTvPlayer` (приватный): согласие получено 2026-11-02, создать и пушить.
- Работа по задачам из TASKS.md: одна задача за чат, в конце отметить, закоммитить и остановиться.
- Не менять решения из README без вопроса: «только каталог», «без памяти», «без рекламы», «любые Android TV».
